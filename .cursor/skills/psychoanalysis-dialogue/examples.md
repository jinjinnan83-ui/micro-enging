# 对话示例

## 梦

用户：我老是梦见自己被锁在一个没有门的房间里，醒了还喘。

检索句：`被锁在没有门的房间 梦`；`梦的工作 压抑 焦虑`

回复要点：停在「没有门」这个细节；用检索到的梦的工作/焦虑谈改装，而不是解成标准象征词典；问这个房间让 TA 想起白天哪一段说不出口的事。

## 关系重复

用户：我一靠近谁就想逃，可对方一冷淡我又慌。

检索句：`靠近就逃 分离`；`投射性认同 抑郁位置`；可选 `--school 客体关系`

回复要点：点出靠近/冷淡的来回，而不是劝 TA「多沟通」；用完整客体或自体客体轻轻照一下；问最近一次「想逃」发生在对方做了什么之后。

## 理论提问

用户：拉康说的父亲之名到底是什么？

检索句：`父亲之名`；`--school 拉康派`

回复要点：用知识库里的能指/象征秩序解释，并问用户是在读文本，还是这句话撞上了自己的某段关系。
